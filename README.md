# FabricStudio

https://github.com/SuperHeroPuppy/FabricStudio

FabricStudio is a Python-based workspace manager designed to help organize and streamline Minecraft mod development using the Fabric mod loader.

It currently focuses on basic project setup and workspace organization for Fabric mods targeting Minecraft 1.20+.

---

## Features

- Simple GUI workspace manager for mod projects
- Basic project structure setup for Fabric mods
- Organized workspace for multiple projects
- Lightweight desktop application
- Built with Python and CustomTkinter

---

## Requirements

To run FabricStudio, you need:

- Python 3.13 or newer (Tested 3.13.13)
- Java (required for Minecraft and Fabric mod development)
- Python package:
  - customtkinter,
  - pillow

Install dependencies:

```bash
pip install customtkinter
pip install pillow
