# FabricStudio 0.0.0

Build: dev00003

---

# Added

- Added integrated texture viewing support directly inside the editor system.
- PNG files now open in a dedicated texture viewer instead of the text editor.
- Added nearest-neighbor texture scaling for pixel-perfect Minecraft texture rendering.
- Added live texture zoom controls with adjustable scaling levels.
- Added automatic editor mode switching based on file type.

# Changed

- Refactored the editor pane to support multiple editor/viewer types.
- Converted the editor content area into a dynamic viewer container system.

# Internal

- Added metadata headers to project source files for improved file tracking and organization.
- Standardized developer/version metadata formatting across tagged files.
