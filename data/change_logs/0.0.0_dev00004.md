# FabricStudio 0.0.0

Build: dev00004

---

# Added

- Added the first phase of the tool generation workflow for workspace content.
- Added support for item generators, including registry name, display name, texture selection, and food attachment options.
- Added a dedicated generator window with pages for creating elements, reviewing generated items, and managing workspace assets.
- Added asset inspection and import support for PNG textures used by generated Minecraft items.

# Changed

- Reworked the tool generator registry to discover generator manifests from project generator packages.
- Updated the workspace UI to expose generators and generated elements in a unified tool panel.

# Internal

- Added generated metadata tracking for created item records, including generated files and creation timestamps.
- Standardized tool generator manifest loading and error handling.
