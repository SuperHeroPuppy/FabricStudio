# FabricStudio 0.0.0

Build: dev00005

---

# Added

- Added a rewritten generator window with a home page for generated chips and a side access bar for Home and Asset Browser.
- Added bottom category navigation for item chip configuration, including Display Setup and Additional Content.
- Added a visual asset browser for textures, audio, and models.
- Added OGG-only audio import support for Minecraft sound assets.
- Added item max stack size configuration from 1 to 64.
- Added creative inventory selection for generated items.
- Added music disc configuration, including sound selection, disc description, sound subtitle, comparator output, duration, sound registration, sounds.json output, language entries, and the Minecraft music disc item tag.
- Added food consumed-result configuration with vanilla items, generated mod items, and other-mod namespaced item support.
- Added a workspace Settings page in the workspace toolbar for editing mod version and project metadata.

# Changed

- Reworked texture import naming to normalize imported asset filenames to lowercase underscores with special characters removed.
- Updated item generation to emit richer Fabric item settings and custom food finish behavior when needed.
- Updated workspace deletion to stop Java and Gradle processes before retrying removal.
- Updated workspace list handling to normalize paths and avoid duplicate workspace rows.
- Updated startup workspace settings to include mod version editing.

# Fixed

- Fixed the generator plus button crash caused by a missing draft value helper.
- Fixed MP3 files being accepted for Minecraft sound assets.
- Fixed generated music discs not being reliably recognized by jukebox behavior.
- Fixed workspace deletion failures caused by Java processes holding files.
- Fixed duplicate workspace entries appearing when recent and local workspace paths referred to the same folder.

# Internal

- Extended item generator manifests with category metadata and additional item configuration fields.
- Added generated metadata preservation for new item settings, music disc fields, and consumed result fields.
