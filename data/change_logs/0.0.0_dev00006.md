# FabricStudio 0.0.0

Build: dev00006

---

# Added

- Added development support for the Block generator.
- Added block chip configuration with registration name, display name, creative inventory, max stack size, hardness, blast resistance, and requires-tool settings.
- Added block sound group selection for material-style sounds such as wood, stone, deepslate, gravel, grass, sand, metal, glass, wool, copper, amethyst, calcite, and mud.
- Added block mining tool type and tool level configuration with generated mineable and needs-tool block tags.
- Added block rotation modes for normal cubes, player-facing horizontal blocks, and pillar/log axis blocks.
- Added a six-side block texture selector for top, bottom, north, south, east, and west cube faces.
- Added block-aware texture importing in the asset browser with an item/block texture target selector.
- Added a create-chip chooser so the blue create button asks whether to create an item or a block.
- Added generated Java registration for blocks and their block items.
- Added generated blockstate JSON, block model JSON, item model JSON, language entries, and generated metadata for blocks.

# Changed

- Updated the generator window to support structured multi-texture fields.
- Reworked the asset browser into a larger side-by-side grid with selection controls grouped at the top.
- Removed the sidebar quick chip selector to leave more space for generated chips.
- Updated generated chip previews to show block texture previews when block texture metadata is available.
- Updated the block tool manifest from placeholder status to supported generator status.

# Fixed

- Fixed block texture imports defaulting only to item texture folders.

# Internal

- Added `tools/block/generator.py` for Minecraft 1.20.1 Fabric block generation.
- Added block generator delete cleanup for generated Java entries and resource files.
