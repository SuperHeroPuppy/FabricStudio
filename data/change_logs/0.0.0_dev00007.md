# FabricStudio 0.0.0

Build: dev00007

---

# Added

- Added model source selection for block and item chips with default/custom options.
- Added custom model selection for blocks and items using imported model JSON assets.
- Added model import targeting in the asset browser for item and block model folders.
- Added default block model presets for cubes, stairs, slabs, fences, fence gates, doors, trapdoors, panes, and walls.
- Added generated model families and blockstates for shape-style blocks such as stairs, slabs, fences, doors, trapdoors, panes, and walls.
- Added matching Fabric block class registration for generated shape-style blocks.

# Changed

- Updated model asset identifiers to use Minecraft model IDs such as `modid:block/model_name` and `modid:item/model_name`.
- Custom block models are referenced as imported assets instead of being overwritten by generated block model files.
- Item and block generated metadata now preserves model source and custom model choices in form data.

# Fixed

- Fixed model imports always defaulting to item model folders.
