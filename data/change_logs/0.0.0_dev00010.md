# FabricStudio 0.0.0

Build: dev00010

---

# Added

- Added generator-only file locks. Files can be locked or unlocked from the workspace Explorer and remain manually editable.
- Added direct host/join workspace collaboration with pairing codes, initial sync, multi-peer file updates, and safe workspace path validation.
- Added collaboration-aware editor refresh that preserves unsaved local edits.
- Added automatic Minecraft sound-event registration for imported OGG assets.
- Added core regression tests for sound events, empty creative groups, file locks, and host/guest synchronization.

# Changed

- Audio asset identifiers now use Minecraft's canonical `mod_id:sound_path` form while remaining compatible with stored `mod_id:sounds/sound_path` values.
- Updated the Minecraft 1.20.1 Fabric generator package to 1.0.2, the item tool to 1.0.4, and the block tool to 1.0.1.
- Made Explorer's **Find Location** action work on Windows, macOS, and Linux.

# Fixed

- Fixed imported sounds not appearing in the `/playsound` command by generating both `sounds.json` entries and server-side `SoundEvent` registrations.
- Fixed items assigned to `none` being silently placed in the Ingredients creative group.
- Fixed PNG previews being overwritten if Save All ran while an image was open.

# Verified

- Ran Python compilation checks across the application, core modules, and generator packages.
- Ran the complete regression suite, including a real host/guest file synchronization test.
