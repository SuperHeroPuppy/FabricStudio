# FabricStudio 0.0.0

Build: dev00011

---

# Added

- Added temporary Internet invitation links for collaborating across different networks without router port forwarding.
- Added an HTTPS long-poll collaboration transport that works through Cloudflare Quick Tunnels while retaining the existing LAN transport.
- Added an explicit consent flow for downloading the official `cloudflared` connector when it is not already installed.
- Added SHA-256 verification against the digest published with the latest official cloudflared release before the downloaded connector is installed.
- Added copyable, high-entropy invitation links whose secret stays in the URL fragment until FabricStudio uses it for authentication.

# Changed

- Replaced the operating-system username default with the neutral `FabricStudio User` display name.
- Split collaboration controls into LAN hosting, Internet hosting, direct joining, and Internet-link joining.
- Updated collaboration documentation and security guidance.

# Verified

- Added an Internet invitation integration test using the complete HTTP host/join transport without contacting an external tunnel.
- Ran all Python compilation, JSON validation, UI import, and regression checks.
