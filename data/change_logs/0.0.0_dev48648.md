# FabricStudio 0.0.0
Build: dev48648

---

# Added

- Versioned project generator loading from "generators/<minecraft-version>-<loader>-generator-<version>".
- Migrated the Minecraft 1.20.1 Fabric generator into "1.20.1-fabric-generator-1.0.0".
- Shared JSON data access helpers for app metadata, Fabric version data, and UI configuration.
- Theme settings and color values now live in "data/theme.json".
- Fabric loader version support is now declared by each generator manifest.

# Changed

- Setup page Minecraft versions are now discovered from installed generators.
- Change log markdown rendering was moved into a reusable UI tool module.
- Tool info, theme helpers, and Fabric version lookup were merged into "core/data_store.py".
- Fabric version dropdown data now comes from installed generator manifests instead of "data/fabric_versions.json".

# Removed

- Removed the standalone Fabric version registry modules and JSON file.
