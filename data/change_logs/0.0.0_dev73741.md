# FabricStudio 0.0.0
Build: dev73741

---

# Added

- Added a GitHub-powered update manager for checking FabricStudio builds.
- Added startup update checking with a changelog preview before entering the main setup page.
- Added update downloads into the local "updates" folder.
- Added remote changelog browsing for update history.

# Changed

- Change logs now live in their own UI page instead of inside "setup_page.py".
- Setup page update and changelog buttons now delegate to separate page files.
- Update downloads are limited to managed builds starting at "dev73741".
- GitHub base update and download URLs now come from "data/information.json".

# Notes

- Updates are downloaded from "SuperHeroPuppy/FabricStudio" on GitHub.
- Older managed builds can be downloaded when GitHub has enough history to resolve the matching changelog commit.
